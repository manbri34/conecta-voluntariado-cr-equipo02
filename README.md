# ConectaVoluntariado CR

Aplicación web full-stack para centralizar la gestión de oportunidades de voluntariado en Costa Rica: organizaciones, actividades, turnos, solicitudes, aprobaciones, asistencia, horas acreditadas y retroalimentación.
